# Ghost Camaro V7 — отчёт о проверках

Minecraft Java 1.20.1, Fabric Loader 0.16.10, Fabric API 0.92.2+1.20.1, Java 17. Проверялся исходный код коммита `c1dc5990d3eebf2b84819e400540caf6fa8f1375`. [Журнал GitHub Actions](https://github.com/Denis18UKS/GhostCamaro/actions/runs/44969366517).

## Сборка и содержимое

Публикуемый JAR извлечён из артефакта GitHub Actions. Контрольная сумма SHA-256 самого JAR: `3df1b48475d81898081583d6f672ccb66237cadbd097c64ec107eeabe34c1d90`. Проверена целостность ZIP/JAR, метаданные мода 7.0.0 и отсутствие классов тестового клиента и GameTest. Внутри 40 blockstates, 604 меша, 38 112 треугольников и данные 62 клипов. В исходниках приложены Gradle wrapper, workflow, игровые и серверные тесты, мастер-модели, генераторы и инструкции.

## Визуальный осмотр и границы проверки

Просмотрены игровые снимки экстерьера, кабины, открытого пустого и заполненного багажника. На виде из салона видны обод и приборы, на паре снимков с кормы видна смена состояния от пустого отсека до укладки коробок. Это осмотр кадров автоматизированного прогона. Ручная поездка с мышью и клавиатурой не проводилась.

Проверка 62 клипов подтверждает загрузку и вычисление трансформаций. Художественная оценка каждого клипа, проверка всех сочетаний повреждений и брони, длительная игра на публичном сервере, модпаки Sodium/Iris, Unity и UE5 в этот прогон не входили. Количественных замеров FPS нет. Световые эффекты фар и динамические зеркала работают в рендерере автомобиля. Фары не меняют освещённость блоков мира. В Blender и FBX игровые зеркала и инвентарь представлены геометрией и материалами; их логика выполняется в Minecraft.
