# Ghost Camaro V6.1 — проверка груза и кузова

Minecraft Java 1.20.1 · Fabric Loader 0.16.10 · Fabric API 0.92.2+1.20.1 · Java 17. [Сборка и журналы GitHub Actions](https://github.com/Denis18UKS/GhostCamaro/actions/runs/44963746543).

## Как проводилась проверка

На выделенном сервере Fabric выполнены два GameTest. Отдельно запущены два процесса графического клиента Minecraft. Первый открыл встроенный сервер для LAN, второй подключился как CargoObserver. Игроки стояли у одной машины. Для каждой стадии тест дождался нужного состояния у обоих клиентов, положения крышки и сохранения PNG каждым наблюдателем. Названия host и observer в архиве соответствуют этим двум клиентам.

| Сценарий | Фактический результат |
|---|---|
| Пустой багажник | Оба клиента получили нулевую загрузку. В первом кадре наблюдателя ещё виден экран загрузки мира. Пустой открытый отсек у обоих виден после полной разгрузки |
| Один предмет | Один хлеб занял слот и дал одну картонную коробку |
| Смешанный груз | Хлеб, зелье, ремкомплект, канистра и слиток дали пять разных типов |
| Все 27 слотов | Оба клиента получили 6 пищевых, 6 медицинских, 5 инструментальных, 5 топливных и 5 универсальных упаковок |
| Удаление отдельного предмета | Удалён хлеб из слота 0. Оба клиента увидели 26 занятых мест |
| Полная разгрузка | После очистки сервер и оба клиента подтвердили пустой отсек |
| Закрытие крышки | Обе копии машины достигли закрытого состояния при 27 занятых слотах. При повторном открытии состав груза сохранился до удаления предмета. Отдельно проверен расчёт зазоров для 27 канистр |
| Сохранение и загрузка | После отключения и повторного запуска мира найдена машина с прежним UUID. Проверены 13 хлебов в слоте 12, 2 железных слитка, визуальный состав, топливо и калибровка зеркала |
| Несколько игроков | Восемь стадий зафиксированы одновременно подключёнными клиентами. Для каждой есть пара снимков |

## Кузов, салон и ресурсы

Проверена машина, повёрнутая на 45°. Свободный угол общего прямоугольника пропускал коллизионный запрос, кузов в центре блокировал его. Луч мимо борта прошёл свободно, луч сверху в багажник попал в машину. Сохранены снимки из кресла и снаружи, а также три изображения отражений. Были повторно проверены запуск двигателя, движение, торможение и аварийное отключение. В моде сохранены 40 клипов, 37 800 треугольников исходной машины и пять дополнительных текстур упаковки.

Проверки графики выполнялись на программном OpenGL без сторонних шейдеров. Положение рук и головы при всех скинах, моделях брони и углах поворота отдельно не измерялось. Автоматическая загрузка меняла серверные слоты напрямую. Проверка конкурентного изъятия использовала штатные обработчики контейнера. Длительная ручная игра двух человек, Sodium, Iris и FPS не проверялись.
