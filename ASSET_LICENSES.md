# Происхождение ресурсов

Геометрия, текстуры и анимации автомобиля перенесены из двух мастер-файлов Ghost Camaro V5, предоставленных для этого проекта. Отдельная лицензия на распространение исходной V5 вместе с материалами не указана.

Пять синтезированных звуков и три пиктограммы созданы для этого мода генератором tools/media.py и предоставлены по CC0 1.0. Звуки железной люковой крышки загружаются средствами Minecraft. Имена Chevrolet и Camaro принадлежат соответствующим правообладателям.

Minecraft загружается Gradle Loom для разработки. В выпускаемый JAR входят код и ресурсы мода. Лицензия Gradle Wrapper — Apache-2.0. Fabric API устанавливается отдельно и распространяется по Apache-2.0.
