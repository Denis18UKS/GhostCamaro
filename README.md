# Ghost Camaro V6.1 · Minecraft Java 1.20.1

Машина Хельге Мейера с управлением, двумя местами и грузовым инвентарём. Оригинал V5 находится в `masters/`. Сборка извлекает из GLB геометрию, текстуры, иерархию и дорожки анимации. Размеры в GLB заданы в метрах, один метр соответствует блоку. Нос мастер-модели смотрит вдоль −X, верх вдоль +Y. В Minecraft при yaw 0 нос направлен вдоль +Z.

## Установка и первая поездка

1. Установите Minecraft Java 1.20.1, Java 17, Fabric Loader 0.16.10 и Fabric API 0.92.2+1.20.1. Положите Fabric API и `GhostCamaro-Fabric-1.20.1-V6.1.jar` в папку `mods` клиента и сервера.
2. Встаньте на ровную площадку со свободным местом впереди. Используйте `/ghostcamaro spawn` или возьмите автомобиль из творческой вкладки Ghost Camaro и нажмите ПКМ по площадке. Альтернатива — `/give @p ghostcamaro:ghost_camaro`.
3. Нажмите ПКМ по левой двери для посадки водителем. Правая дверь ведёт на пассажирское место. Запустите V8 клавишей R, дождитесь оборотов холостого хода, нажмите W. Shift выводит из машины.

| Действие | Управление по умолчанию |
|---|---|
| Газ, руль | W, A/D |
| Рабочий тормоз, затем задний ход | S |
| Экстренное торможение и ручник | Удерживать пробел |
| Зажигание, ближний свет | R, L |
| Левый, правый указатель, аварийка | Z, X, C |
| Гудок, дворники | H, P |
| Салон, вид сзади, вид спереди | F5 |
| Вид с капота | V в режиме первого лица |
| Регулировка зеркала | Навести взгляд на зеркало, M, сдвинуть мышь. ЛКМ завершает, ПКМ сбрасывает оба угла |
| Открыть дверь снаружи | Shift + ПКМ по боковине |
| Капот | ПКМ спереди на остановленной машине |
| Багажник | ПКМ с кормы открывает крышку и 27 слотов. Закрыть экран, затем Shift + ПКМ по корме закрывает крышку |
| Окна, двери из салона, капот, багажник, бардачок и быстрые взгляды в зеркала | Назначить клавиши в настройках управления, категория Ghost Camaro |

Бак и прочность пополняются на стоянке щелчком по кузову с канистрой или ремкомплектом. При повреждении ниже 45% появляется светлый дым. При 10% и меньше двигатель останавливается, после густого дыма проигрывается финальный эффект. Он сохраняет блоки мира и содержимое багажника. Ремонт сбрасывает состояние отказа. С открытыми капотом или багажником движение заблокировано.

Команда `/ghostcamaro status` показывает состояние машины поблизости или машины игрока. Для `spawn`, `repair`, `refuel` требуется уровень разрешений 2.

## Груз в багажнике

ПКМ с кормы открывает существующий контейнер на 27 слотов. При открытой крышке можно навести курсор прямо на груз. Один занятый слот отображается одной упаковкой. Стаки дополняют уже занятую упаковку. Пять видов упаковок обозначают продукты, медикаменты, инструменты, топливо и прочие предметы. Канистра и ремкомплект мода распознаются отдельно. Например, зелья и мёд попадают в медицинские контейнеры, хлеб в картон, слитки в универсальные посылки.

Первый слой вмещает 15 упаковок, второй — 12. Верхняя упаковка опирается на упаковку под ней. Высота опоры зависит от корпуса и ручки канистры. При ускорении, рулении и торможении слегка наклоняются только модели упаковок. Блокировка движения с открытой крышкой сохранена.

Сервер пересчитывает пять счётчиков только при изменении инвентаря и синхронизирует их одним целым числом на автомобиль. Рендер использует пять общих моделей. Коробки нельзя подобрать или уничтожить отдельно. При загрузке старого мира вид груза восстанавливается по сохранённым слотам.

## Кузов, остекление и посадка

Для столкновений и наведения используются отдельные секции кузова. Общий осевой прямоугольник остаётся частью пространственного поиска Minecraft. **F3+B** переключает ванильную отладочную рамку и синий луч направления взгляда. При включении диагностики на диагонально стоящей машине виден внешний прямоугольник поиска. Обычный режим игры эти линии не рисует.

Модель сидящего игрока ниже, руки водителя ориентированы на обод. Для первого лица используются руки со скином игрока. Лобовое стекло имеет более светлый оттенок, чем боковые стёкла. В исходной геометрии V5 сохранены руль, приборы, капот, крышка багажника и все 40 анимаций.

## Зеркала и конфигурация

Три клиентские камеры рендерят Minecraft-мир в три отдельные текстуры, наложенные на стёкла. Они обновляются у игрока в салоне. Каждая регулировка хранится в NBT машины. Файлы в папке `config` создаются при первом запуске. Изменения применяются после перезапуска.

- `ghostcamaro-client.json` — ширина отражения `mirrorWidth` (по умолчанию 256, значение 0 отключает), `mirrorFps` (12, предел 30), дистанция камеры `chaseDistance`, высота глаз `eyeHeight`, показ `hud`.
- `ghostcamaro.json` — скорость, ускорение, два замедления, ёмкость бака, расход на холостом ходу и в движении, урон от столкновения. Скорость задана в блоках за тик, ускорение в блоках за тик².
- Стрелки, поворотники, стопы и светящиеся части фар входят в модель. Световой след от фар взят из V5. Уровни освещённости блоков мира фары не меняют.
- Содержимое багажника, положения зеркал, топливо, повреждения и переключатели сохраняются с Entity. При выгрузке вещи остаются в NBT, при уничтожении Entity выпадают. В API `Cargo` доступны подсчёт, обмен предметов с откатом и подписка на изменения.
- Совместимость зеркал с Sodium, Iris и шейдерпаками требует отдельной проверки. Поддержаны регулировка отражения по двум осям и быстрый взгляд. Складывание корпусов зеркал, независимый масштаб HUD и отдельные уровни детализации отсутствуют.

## Сборка и исходники

Из корня проекта на Java 17 с Python 3 выполните `bash gradlew build` (Windows: `gradlew.bat build`, команда `python3` должна быть доступна). Результат — `build/libs/GhostCamaro-Fabric-1.20.1-V6.1.jar`. Используйте Gradle wrapper из проекта. При первой сборке Gradle скачивает зависимости.

`tools/port.py` заново создаёт четыре атласа, меши и таблицы анимаций при сборке. `tools/media.py` восстанавливает синтезированные звуки и пиктограммы (Pillow, FFmpeg). Для обычной сборки звуки и пиктограммы уже приложены. Редактируемый оригинал Blockbench находится в `masters/Ghost_Camaro_V5.bbmodel`. После изменения мастер-модели обновите GLB перед сборкой. Порт рассчитывает на именованные узлы V5.

См. ANIMATIONS.md для сопоставления клипов, TEST_REPORT.md для границ проверки, ASSET_LICENSES.md для происхождения ресурсов.
