# Работа с моделью V7

Откройте GhostCamaro-V7.blend через File → Open. Проект сохранён в Blender 4.3.2, единицы метрические. Автомобиль ориентирован носом вдоль −X, вертикаль Blender +Z. В GLB вертикаль +Y. Каждый метр в игре соответствует одному блоку.

Геометрия состоит из 604 отдельных мешей. Для редактирования поверхности выберите меш и перейдите в Edit Mode. Имена деталей совпадают с именами мастер-проекта. Подвижные детали привязаны к костям GhostCamaro_Rig; пивоты колёс лежат на осях. Четыре изображения упакованы в .blend и приложены в Textures.

Для воспроизведения выберите GhostCamaro_Rig, откройте Dope Sheet → Action Editor и назначьте нужный Action, например Door_L_Open. Запустите воспроизведение с первого кадра. Альтернативно включите нужную дорожку NLA. При открытии дорожки приглушены, чтобы в нейтральной позе не складывались все события одновременно. Скорость 24 кадра/с.

Для FBX используйте File → Import → FBX с включённой загрузкой анимаций. После импорта имена Actions могут получить префикс арматуры. FBX содержит жёстко привязанные к костям отдельные меши, запечённые анимации и встроенные изображения. В GLB сохранены отдельные узлы исходной иерархии. Поведение мода, отражения мира, инвентарь и расход топлива выполняются кодом Fabric.

Для повторного экспорта на Blender 4.3 запустите из корня исходников сначала python3 tools/port.py, затем blender -b --python tools/v7/blender_export.py. Экспортёр открывает GLB, создаёт сцену и FBX, повторно импортирует FBX и составляет FBX_CHECK.json. В Unity или UE5 импортируйте FBX с анимациями и проверьте масштаб по длине кузова около пяти метров. Импорт в эти два редактора отдельно не проверялся.
